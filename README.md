A standalone GitHub-compatible git forge in a single Node.js process: git smart HTTP (protocol v2 and v0), the REST v3 API, GraphQL and MCP, all served from its own in-memory store. No UI, no database, no git binary — standard library only.

## Run it

```sh
node main.ts
```
